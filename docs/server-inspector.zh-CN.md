# 下载服务器地理位置与延迟检查器

Motrix Turbo 为 HTTP、HTTPS 和 FTP 下载任务提供活动镜像、连接节点以及网络状况的实时监控视图。

## 功能概述

在进行多连接或多镜像下载时，底层下载引擎会并发连接主服务器和各个镜像节点。**服务器 (Servers)** 检查器标签页提供这些连接的实时遥测信息：

- **服务器节点 (Endpoint)**：正在传输数据块的远程 IP 地址与目标端口 (`IP:端口`)。
- **来源链接 (URI)**：当前生效的镜像或资源请求 URI。
- **下载速度**：各个服务器节点的实时传输速率。
- **GeoIP 地理位置**：基于本地离线 GeoIP 数据库解析的国旗及国家/地区代码。
- **估算延迟**：实测网络往返往返时间（毫秒）。

## 打开服务器检查器

1. 在任务列表中选中任意正在下载、暂停或完成的 HTTP/HTTPS/FTP 任务。
2. 打开**任务详情检查器**抽屉。
3. 点击检查器顶部标签栏的**服务器**图标。

> [!NOTE]
> BitTorrent 和 Magnet 任务使用专用的**节点 (Peers)** 和 **Tracker** 检查器标签页，不会显示 HTTP/FTP 服务器标签页。

## 地理位置解析

地理位置解析依托 Motrix 本地离线 GeoIP 服务：
- 所有 IP 地址解析完全在本地完成，查询离线数据库。
- IP 查询过程中不会向任何第三方追踪服务发送网络请求。
- 若 GeoIP 功能未启用或离线数据库尚未安装，列表依然会显示节点、链接、传输速率和延迟信息。
