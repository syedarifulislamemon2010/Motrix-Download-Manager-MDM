# 崩溃报告与诊断

Motrix 提供了注重隐私的崩溃报告与诊断工作流，旨在让问题反馈迅速、详尽，同时杜绝凭据或个人隐私信息泄漏。

## 功能特性

- **GitHub Issue 预填链接**:
  - 自动将运行时错误、操作系统架构、应用版本、便携模式状态以及堆栈追踪格式化为规范的 Markdown 问题模板。
  - 生成 `https://github.com/agalwood/Motrix/issues/new?title=...&body=...` 链接，点击即可在默认浏览器中一键打开。
- **隐私与路径自动脱敏**:
  - 自动脱敏 Windows 用户个人文件夹路径（`C:\Users\<user>\` -> `C:\Users\<redacted-user>\`）、macOS 路径（`/Users/<user>/`）和 Linux 路径（`/home/<user>/`）。
  - 脱敏敏感凭据信息，包括 aria2 RPC 密钥（`--rpc-secret`）、HTTP Authorization Bearer 令牌、API 密钥以及 URL 查询参数（`token=`、`access_token=`、`secret=` 等）。
- **安全截断算法**:
  - 针对浏览器 URL 最大长度限制（约 7,000 字符），采用二分法精确适应算法，在超长诊断日志时安全截断并附加说明，避免 URL 超长导致请求失效。
- **多入口集成**:
  - **应用菜单**: `帮助` -> `反馈问题` 直接打开预填问题报告。
  - **关于对话框**: 资源菜单中新增“反馈问题”快捷入口。
  - **渲染器恢复屏幕**: 当渲染层发生未捕获致命错误时，可在故障回退界面点击“在 GitHub 上反馈”。
  - **路由错误边界**: 在页面导航异常界面可直接发起问题报告。
