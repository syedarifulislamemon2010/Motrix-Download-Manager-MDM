# 压缩包自动解压

Motrix Turbo 提供了在任务下载完成后自动解压压缩包的功能。

## 功能特性

- **格式支持**:
  - **ZIP**: 纯 JavaScript 原生流式解压，无需本地依赖。
  - **7-Zip (`.7z`) 与 RAR (`.rar`)**: 自动调用本机的 7-Zip (`7z` 或 `7z.exe`) 命令行工具解压。
- **安全与 Zip-Slip 防护**:
  - 严格拦截路径穿越尝试（如包含 `..` 的恶意相对路径）。
  - Windows 保留设备名称自动转义（如 `CON`、`PRN`、`AUX`、`NUL`、`COM1-9`、`LPT1-9`）。
  - Windows 超长路径（>260字符）原生适配（通过 `\\?\` 前缀）。
  - 拒绝提取可能越界的符号链接。
  - 解压异常中断时自动清理残余文件。
- **解压目标位置**:
  - `subfolder`: 自动创建与压缩包同名的子文件夹解压。
  - `in_place`: 直接解压到当前下载目录。
- **清理源文件**:
  - 可选开关 `deleteArchiveAfterExtract`：在解压成功后自动删除源压缩包。
- **密码库管理**:
  - 支持配置常用密码列表，遇加密压缩包时按顺序自动尝试。

## 配置方式

打开 **设置** > **下载** > **压缩包自动解压**:

- **下载完成后自动解压**: 开启或关闭自动解压功能。
- **解压目标位置**: 选择“子文件夹”或“当前下载文件夹”。
- **支持的格式**: 自由勾选 ZIP、7-Zip 或 RAR 格式。
- **解压后删除原压缩包**: 勾选后将在解压成功时安全删除原始压缩包。
- **7-Zip 可执行文件路径**: 自定义指定 `7z.exe` 路径，留空将自动在标准安装目录与环境变量 PATH 中检测。
- **解压密码库**: 添加或删除解压常用密码。
