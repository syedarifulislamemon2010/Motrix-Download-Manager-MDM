# 辅助工具安全管理 (yt-dlp / gallery-dl / Deno)

Motrix Turbo 为流媒体与相册解析外部工具（包括 **yt-dlp**、**gallery-dl** 与 **Deno**）提供了原生且安全的生命周期与版本管理机制。

## 托管的辅助工具

1. **yt-dlp**
   - 高性能音视频提取引擎，支持数千个流媒体与视频托管网站。
   - 锁定验证版本：`2025.02.19`。
   - Windows 可执行文件：`yt-dlp.exe`（单文件独立程序）。

2. **gallery-dl**
   - 图像画廊、画册、漫画及社交媒体图片批量下载器。
   - 锁定验证版本：`1.28.5`。
   - Windows 可执行文件：`gallery-dl.exe`（单文件独立程序）。

3. **Deno 运行时**
   - 现代化安全 JavaScript 与 TypeScript 脚本运行时，支持高级 URL 解析脚本与抓取扩展。
   - 锁定验证版本：`v2.2.0`。
   - Windows 可执行文件：`deno.exe`（通过安全解压流释放）。

## 安全与校验保障

- **严格的 SHA-256 校验**：所有下载的文件均采用流式哈希计算，严格对照代码中硬编码的发行清单进行比对。任意字节偏差均会导致下载文件立即被清理销毁。
- **防止 Zip-Slip 目录穿越**：压缩包解压过程严格限制在目标受管目录内，彻底防御跨目录逃逸（`..`）、绝对路径越界及 Windows 保留设备名称（`CON`、`NUL`、`AUX` 等）。
- **用户数据区隔离**：安装的外部程序均独立存放于用户数据目录下（Windows 为 `%APPDATA%\Motrix\binaries\<tool>\`，macOS/Linux 为对应的数据目录），绝不污染全局系统目录或写入注册表。
- **可用性测试验证**：安装落盘后立即执行带 5 秒超时保护的 `--version` 命令，确保程序具备执行权限且运行正常。

## 配置与自定义路径

可以在 **设置** > **集成** > **辅助工具** 中统一监控与管理：

- **一键安装 / 检查更新**：无需配置 Python 环境或手动下载解压，一键即可拉取并校验安装。
- **自定义程序路径**：若系统中已存在自定义或更高版本的程序，可展开 **自定义路径** 输入可执行文件的绝对路径。
- **环境变量支持**：当未配置自定义路径时，Motrix 也会自动检测下列环境变量：
  - `MOTRIX_YTDLP_BIN`
  - `MOTRIX_GALLERYDL_BIN`
  - `MOTRIX_DENO_BIN`
